## 🔧 Getting Started

### 1. Clone the repository
```bash
git clone git@github.com:Adams-404/Esux.git
cd Esux
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Visit **[http://localhost:3000](http://localhost:3000)** inside your browser to see the liquid glass in motion layouts setups alignment.
